# Contributing

Thank you for taking an interest in The Spoke Calculator.

## Issues are welcome

Bug reports, ideas, and questions are all useful. Please open an
[issue](https://github.com/llongmane584/the-spoke-calculator/issues).

For a bug report, the following makes it much easier to reproduce:

- the values you entered and the result you expected
- what happened instead
- the browser and the device you used

## Pull requests are not accepted

This project is maintained by a single author, and every change goes through that workflow.
Pull requests opened from a fork are closed automatically, regardless of what they contain —
the close says nothing about the quality of the change.

If you have a fix in mind, please describe it in an issue instead. A clearly written issue is
more useful here than a patch.

# コントリビューションについて

The Spoke Calculator に関心をお寄せいただきありがとうございます。

## issue は歓迎します

不具合の報告、要望、質問はいつでも歓迎します。
[issue](https://github.com/llongmane584/the-spoke-calculator/issues) からお知らせください。

不具合の報告では、次の情報があると再現が容易になります。

- 入力した値と、期待していた結果
- 実際に起きたこと
- 使用したブラウザーと端末

## Pull Request は受け付けていません

このプロジェクトは作者 1 人で管理しており、変更はすべてその流れの中で行っています。
fork から出された Pull Request は、内容にかかわらず自動でクローズされます。
クローズは変更の良し悪しを示すものではありません。

修正の案がある場合は、issue に書いてお知らせください。ここではパッチよりも、
よく書かれた issue のほうが役に立ちます。
