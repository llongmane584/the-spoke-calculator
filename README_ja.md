# 自転車スポーク長計算機

[計算機を開く](https://llongmane584.github.io/the-spoke-calculator/) · [English](README.md)

自転車のホイール組みに必要な左右のスポーク長を求めるWebアプリケーションです。各寸法と組み方を入力すると、計算結果が即座に更新されます。

計算は12 mmのニップルを前提としています。リムの内壁厚、ニップル長、測定誤差、部品の公差によって必要な長さは変わるため、注文・組み立ての前に実物の部品と照合してください。

## 主な機能

- リムオフセットと左右個別の組み方に対応したスポーク長のリアルタイム計算
- ホイール、ハブ、リムのプリセット
- ローカル保存、JSON入出力、URL共有、スポーク再利用比較
- 日本語・英語、ライト・ダークテーマ、レスポンシブ表示、Webアプリのインストール

詳しい操作方法は、アプリ内メニューの「使い方」から確認できます。

## 開発

```bash
pnpm install
pnpm dev
```

変更を提出する前に、次のチェックを実行してください。

```bash
pnpm lint
pnpm test
pnpm build
```
